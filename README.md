# 🏦 ATM პროექტი

C# / .NET 10-ზე შექმნილი კონსოლური ბანკომატის სისტემა.

## 📌 რას აკეთებს პროექტი

- რეგისტრაცია და ავტორიზაცია
- ბალანსის ნახვა
- თანხის შეტანა და გატანა
- სესხის მოთხოვნა
- სესხის დამტკიცება / უარყოფა
- სესხების ისტორიის ნახვა
- ტრანზაქციების ისტორიის ნახვა
- მონაცემების შენახვა JSON ფაილებში
- მომხმარებლისა და ადმინისტრატორის როლები

## 🚀 გაშვება

პროექტის საქაღალდეში გაუშვით ტერმინალში:

```bash
dotnet restore
dotnet run
```
